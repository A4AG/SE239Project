For Week 6, we wrote a Python server and a client and ran both on the same computer. The client connected over TCP, sent a short message, and showed the reply. The server sent back the same text, so we could see that the message made it both ways. For Week 8, we gave each client connection its own thread so the server could handle more than one client at a time. We tested it by opening three client windows, registering a different account in each one, and checking that all three stayed signed in at the same time.
